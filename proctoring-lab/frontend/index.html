PROBLEM A · PRACTICE

Sum of integers

Easy
Time limit: simulatedMemory limit: simulatedJudge: unavailable

Given N integers, output their sum. The values may be positive, negative, or zero.

Input format

The first line contains N. The second line contains N space-separated integers.

Output format

Print one integer: the sum of the given values.

Constraints

  • 1 ≤ N ≤ 100,000
  • −1,000,000 ≤ each integer ≤ 1,000,000

Sample input 

4
3 7 -2 5

Sample output

13

Explanation

3 + 7 + (−2) + 5 = 13.

Practice only: code is not executed or graded, and no source code is sent to the server.
